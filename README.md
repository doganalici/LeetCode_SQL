## 📌 Hakkında

Bu repo, LeetCode üzerindeki SQL kategorisinde yer alan soruların çözüm kodlarını ve açıklamalarını düzenli bir klasör yapısıyla barındırır. Temel veri çekme işlemlerinden ileri düzey JOIN, AGGREGATION, CASE WHEN ve pencere fonksiyonlarına kadar geniş bir yelpazeyi kapsar.

## 📂 Repo Yapısı
